# Portfolio — Local Development

## Run locally

Install dependencies:

```
npm install
```

Run dev server:

```
npm run dev
```

Build for production:

```
npm run build
```

## Update content
- Projects are in `src/data/projects.js`.
- Experience is in `src/data/experience.js`.
- Components are in `src/components/`.

Replace placeholder links and email addresses with your real links.
